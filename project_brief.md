# My agent: travel-concierge
One-liner: A conversational agent that helps travelers plan custom trips and discover destinations with a catalog of travel itineraries and venues.

Tool coverage:
- Memory: Remembers travel style, budget, past visited locations, and dietary/accommodation preferences across sessions
- Tools: Looks up flights, hotel availability, and local venue details
- Catalog/UI: Collection of destination cards, hotel options, and daily itinerary schedules (rendered as A2UI cards/tables)
- Image gen: Generates custom preview images of scenic locations and accommodations
- Sandbox: Calculates trip budgets, currency conversions, and itinerary time allocations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for budget calculations
